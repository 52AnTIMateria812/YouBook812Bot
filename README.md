#  Book Recommendation Bot

Telegram-бот для рекомендации книг на основе предпочтений пользователя с использованием машинного обучения.

##  Функционал
- Рекомендации книг по жанрам
- Система оценки книг (`/rate`)
- Персонализированные рекомендации (`/recommend`)
- Выбор предпочтительных жанров (`/genres`)
